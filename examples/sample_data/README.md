# 示例数据（合成，不是真实行情）

让新机器在没有真实数据的情况下也能跑通全部功能。**数据是程序合成的，价格不是任何一天的真实报价，预测结果没有交易意义。**

## 怎么生成的

由 `tools/make_sample_data.py` 用真实历史"校准"生成，方法是匹配式分段抽样（matched block bootstrap）：

1. 把每个真实交易日拆成与价格水平无关的量：
   - 开/高/低/收相对前收的比例；
   - 成交量；
   - VIX 点位、DIX、GEX/价格²；
   - US500 相对 SPX 的比例；
   - 当天 30 分钟线、5 分钟线相对前收的比例。
2. 合成日历用真实的 NYSE 开市日。每次抽 20 个连续真实日；每段开头从 VIX 最接近当前水平的 15 个候选里随机选一个，让波动环境连续。
3. 2020 年起只从有完整 30 分钟线的真实日里抽，2024-08 起只从同时有完整 5 分钟线的真实日里抽，所以同一天的日线、30 分钟、5 分钟彼此一致。
4. 价格从 1500 点起，按抽到的比例逐日连乘，走出一条和真实 SPX 不同的路径。

和真实数据的对照（2011-05 至 2026-11）：

| 指标 | 真实 | 合成 |
|---|---|---|
| 日收益标准差 | 1.08% | 1.09% |
| 涨跌超过 2% 的天数 | 5.6% | 4.7% |
| 日内振幅中位数 | 0.89% | 0.93% |
| VIX 均值 | 18.1 | 18.9 |
| 收益与 VIX 变化的相关系数 | -0.74 | -0.76 |
| 波动聚集（\|收益\| 的自相关） | 0.33 | 0.30 |
| 和真实收盘价相同的天数 | — | 0 |
| 与真实同日收益的相关系数 | — | -0.004 |

## 文件

| 文件 | 内容 |
|---|---|
| `data/SP_SPX, 1D.csv`、`data/US500_1D.csv`、`data/CBOE_DLY_VIX.csv` | 合成日线 |
| `data/DIX.csv` | 合成 DIX / GEX |
| `intraday/SPX_30min.csv`、`intraday/SPX_5min.csv` | 合成 30 / 5 分钟线（`date`, `tod` 为美西时间） |
| `data/nyse_open_days.csv`、`data/event_calendar.csv` | 真实的公开日历（交易日、FOMC/OPEX），不是行情数据 |

## 安装

```bash
python tools/install_sample_data.py
```

安装时整段日期会平移，最后一天对齐到"美西时间今天及以前的最后一个交易日"（和日跑体检的口径一致）。已有的文件不会被覆盖；加 `--force` 才覆盖。
